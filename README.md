# Frieren

**Frozen Graph Refinement via Item Relation Estimation for Multimodal Recommendation**

Frieren estimates item relations from knowledge, interactions, or learned content–behavior representations. Its frozen graphs can be reused by downstream recommendation models. This package contains the three estimators, optional behavioral neighborhood weighting (BNW), FREEDOM training, transfer adapters, and graph–parameter cross-evaluation.

## Installation

Requires Python 3.10 or newer and PyTorch 2.1 or newer.

```bash
python -m pip install -e ".[dev]"
python -m frieren --help
```

Install a CUDA-enabled PyTorch build to train on a GPU, then pass `--device cuda`. CPU execution is sufficient for the tests and synthetic example.

## Synthetic example

Run these commands from this directory:

```bash
python scripts/make_demo.py
frieren build-reference --dataset data/demo/dataset.json --output artifacts/demo/F.pt
frieren build-k --dataset data/demo/dataset.json --embeddings data/demo/knowledge.npy --output artifacts/demo/K.pt
frieren build-b --dataset data/demo/dataset.json --fallback artifacts/demo/F.pt --output artifacts/demo/B.pt
frieren train-l --dataset data/demo/dataset.json --config configs/demo_L.json --output-dir outputs/demo/L
frieren export-l --dataset data/demo/dataset.json --checkpoint outputs/demo/L/direct_best.pt --output artifacts/demo/L.pt
frieren refine-bgnw --dataset data/demo/dataset.json --graph artifacts/demo/L.pt --output artifacts/demo/L_BNW.pt
frieren train-freedom --dataset data/demo/dataset.json --graph artifacts/demo/L_BNW.pt --config configs/demo_FREEDOM.json --output-dir outputs/demo/FREEDOM
```

`python -m frieren` can replace `frieren`. The `refine-bgnw` command name is retained for compatibility. The example uses synthetic data and short training budgets; it does not reproduce a benchmark score.

An end-to-end check also exercises all three transfer adapters and frozen-parameter replay:

```bash
python scripts/smoke_framework.py --output outputs/smoke
```

Choose a new output directory for each invocation.

## Data

Create a manifest following [the data format](docs/DATA_AND_ARTIFACTS.md) and `configs/dataset.example.json`. Features and graph nodes must follow the same item mapping. Training, validation, and test splits are supplied explicitly and are never regenerated by the loader.

Frieren-K accepts pretrained item embeddings. For entity-level embeddings, supply both `--entity-ids` and `--item-to-entity` to extract and reorder items. NativE pretraining is an upstream dependency and is not reimplemented here.

Graph files contain a sparse operator plus a JSON sidecar with item order, construction settings, and SHA256 signatures. Rows identify receivers and columns identify senders: propagation is `A @ H`.

## Training protocols

The paper's downstream protocol is in `configs/paper/FREEDOM.json`: at most 1,000 epochs, stopping after 40 consecutive epochs without a strict improvement in validation Recall@20. It uses 64-dimensional embeddings, two user–item layers, one item-graph layer, dropout 0.3, Adam at 0.001, and batch size 2,048.

```bash
frieren train-freedom --dataset data/example/dataset.json --graph artifacts/example/L.pt --config configs/paper/FREEDOM.json --output-dir outputs/example/FREEDOM --device cuda
```

Frieren-L upstream training is separate: `configs/paper/L.json` uses at most 200 epochs, with patience 20 for both side and direct validation scores. The direct-validation-selected checkpoint supplies the exported graph. `configs/UB.json`, `configs/U1.json`, and `configs/U0.json` specify its component variants. Neighborhood size and optional BNW are supplied when exporting a graph.

Generic API defaults retain the earlier settings: FREEDOM uses a fixed 500-epoch budget unless `patience` is set; Frieren-L uses 200 epochs with patience 20. A FREEDOM command can override patience with `--patience 40`.

`last.pt` stores the final model, optimizer, scheduler, training order, sampling pool, random states, best score, and early-stopping count. Resume it explicitly with `--resume`; the count is preserved and completed early stopping is not restarted. `best.pt` is selected using validation Recall@20. Test evaluation follows checkpoint selection. Load training checkpoints only from trusted sources.

## Transfer and cross-evaluation

FREEDOM consumes the saved operator directly. MENTOR, SMORE, and MSCA adapters symmetrize and normalize the source graph before replacing `mm_adj`, `fusion_adj`, and `struct_original_adj`, respectively. Use those models' original implementations; the adapters retain their other views. See [model integration](docs/BACKBONE_INTEGRATION.md).

`frieren replay` freezes a trained FREEDOM checkpoint and evaluates several graphs without optimizer updates. Its `--graphs` argument is a JSON mapping from names to graph paths, resolved relative to that JSON file. Repeating replay for each trained checkpoint forms a graph-by-parameter matrix.

## Tests

```bash
python -m pytest tests -q
```

Tests cover EASE's constrained solution and orientation, entity mapping, graph conversion, BNW constraints, forward values and gradients, exact resume, ES40, and frozen replay. Optional parity tests use archived research snapshots when available and are skipped in a standalone checkout.

This package supplies the core framework and executable interfaces. Paper results also require the corresponding data, pretrained knowledge embeddings, selected graph configurations, and external model implementations. Full benchmark GPU trajectories are not established by the synthetic test.
